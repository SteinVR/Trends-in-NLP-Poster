# Редактируемый постер Legal RAG

`legal-rag-poster.pptx` — один слайд A1 (594 × 841 мм), английский текст, точная по расположению копия HTML-макета. Автор оставлен как `[AUTHOR NAME]`.

## Перед открытием

Установите оба шрифта из папки `fonts`: NotoSans-Regular.ttf и NotoSans-Bold.ttf. В Windows откройте файлы и нажмите «Установить», затем заново откройте PowerPoint. В macOS используйте Font Book. Шрифты приложены отдельно, а не встроены в PPTX. Без них редактор может заменить гарнитуру и изменить расположение текста.

## Как редактировать

- Текст: щёлкните внутри текстового поля. Для точного совпадения с оригиналом сохранены явные переносы строк. Если существенно меняете длину текста, отрегулируйте переносы и размер поля.
- Перемещение: выделите объект или группу и перетащите. Стрелки на клавиатуре подходят для небольших смещений.
- Блок схемы: рамка и две подписи сгруппированы. Один щелчок выбирает группу; повторный щелчок — элемент внутри неё. При необходимости используйте «Разгруппировать».
- Стрелки схемы — отдельные фигуры. После перемещения блоков их следует подвинуть вручную.
- Для перекрывающихся элементов откройте «Область выделения»: основные объекты названы по их содержимому.
- Графики и логотип: отдельные SVG-изображения. Их можно перемещать, заменять и масштабировать без потери чёткости. Это не диаграммы Excel: значения и подписи графиков не являются текстовыми полями PowerPoint. Для изменения чисел обновите исходные SVG в `../poster/assets/` и замените изображения.
- Перед экспортом в PDF проверьте длинные подписи и нижний край постера. Не меняйте размер слайда на стандартный 16:9.

После ручных правок PPTX становится самостоятельным макетом. HTML и PPTX автоматически не синхронизируются.

Исходный макет: `../poster/index.html`. Данные экспериментов: `../results/metrics.csv`. Публичная ссылка ведёт на этот репозиторий с реализацией, протоколом и результатами исследования.
