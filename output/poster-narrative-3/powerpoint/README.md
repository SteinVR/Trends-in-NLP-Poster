# Редактируемый постер Legal RAG

`legal-rag-poster.pptx` — один слайд A1 (594 × 841 мм), английский текст, макет по утверждённой HTML-версии от 2026-09-23. Имена авторов и заглушка автора отсутствуют.

`preview.png` показывает рендер текущего PPTX. Архив `legal-rag-poster-with-fonts.zip` содержит этот же PPTX, данную инструкцию, шрифты и их лицензию.

## Перед открытием

Установите оба шрифта из папки `fonts`: NotoSans-Regular.ttf и NotoSans-Bold.ttf. В Windows откройте файлы и нажмите «Установить», затем заново откройте PowerPoint. В macOS используйте Font Book. Шрифты приложены отдельно, а не встроены в PPTX. Без них редактор может заменить гарнитуру и изменить расположение текста.

## Как редактировать

- Текст: щёлкните внутри текстового поля. Для точного совпадения с оригиналом сохранены явные переносы строк. Если существенно меняете длину текста, отрегулируйте переносы и размер поля.
- Перемещение: выделите объект или группу и перетащите. Стрелки на клавиатуре подходят для небольших смещений.
- Блок схемы: карточка, подписи, иконка и исходящая стрелка сгруппированы. Один щелчок выбирает группу; повторный щелчок — элемент внутри неё. При необходимости используйте «Разгруппировать».
- Стрелки схемы — редактируемые фигуры. После перемещения блоков проверьте их соединения и при необходимости подвиньте стрелки вручную.
- Для перекрывающихся элементов откройте «Область выделения»: основные объекты названы по их содержимому.
- Графики, иконки и логотип: отдельные SVG-изображения. Их можно перемещать, заменять и масштабировать без потери чёткости. Это не диаграммы Excel: значения и подписи графиков не являются текстовыми полями PowerPoint. Исходные графики находятся в `../results/`: `pipeline-metrics.svg` и `ocr-control.svg`. В копии для PPTX обводка чисел адаптирована для совместимого отображения SVG.
- Перед экспортом в PDF проверьте длинные подписи и нижний край постера. Не меняйте размер слайда на стандартный 16:9.

После ручных правок PPTX становится самостоятельным макетом. HTML и PPTX автоматически не синхронизируются.

Исходный макет в репозитории: `../poster/index.html`. Данные экспериментов: `../results/metrics.csv`.
